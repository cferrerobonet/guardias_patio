# ✅ Checklist de Compilación Windows

## Pre-Compilación

- [ ] Python 3.13+ instalado
- [ ] Inno Setup 6.5.4+ instalado en `C:\Program Files (x86)\Inno Setup 6\`
- [ ] Virtual environment creado en `C:\dev\guardias-patio\.venv`
- [ ] Todas las dependencias instaladas:
  ```powershell
  C:\dev\guardias-patio\.venv\Scripts\pip.exe install -r requirements.txt
  ```
- [ ] **CRÍTICO**: email_validator desinstalado:
  ```powershell
  C:\dev\guardias-patio\.venv\Scripts\pip.exe uninstall -y email_validator
  ```
- [ ] Versión actualizada en:
  - [ ] `version_info.txt` (líneas 10-11 y 33-38)
  - [ ] `installer_windows.iss` (línea 6)
- [ ] Git commit de cambios pendientes

## Durante Compilación

- [ ] Ejecutar script automatizado:
  ```powershell
  .\scripts\build_windows.ps1
  ```
- [ ] **NO interrumpir** el proceso con Ctrl+C
- [ ] **NO usar** comandos con `Start-Sleep` que puedan cancelar procesos en background
- [ ] Esperar mensaje: "✅ COMPILACIÓN COMPLETADA EXITOSAMENTE"

## Post-Compilación: Verificación

- [ ] Ejecutable generado: `C:\dev\gdp_dist\GuardiasDePatio\GuardiasDePatio.exe`
- [ ] Tamaño ejecutable: ~18-20 MB
- [ ] matplotlib incluido:
  ```powershell
  Test-Path "C:\dev\gdp_dist\GuardiasDePatio\_internal\matplotlib"
  ```
- [ ] reportlab incluido:
  ```powershell
  Test-Path "C:\dev\gdp_dist\GuardiasDePatio\_internal\reportlab"
  ```
- [ ] email_validator NO presente:
  ```powershell
  Get-ChildItem "C:\dev\gdp_dist\GuardiasDePatio\_internal" -Filter "*email_validator*"
  # Debe estar vacío
  ```
- [ ] Instalador generado: `C:\dev\gdp_out\GuardiasDePatio-X.X.X-Windows-Setup.exe`
- [ ] Tamaño instalador: ~60-70 MB

## En Caso de Errores

### Error: matplotlib faltante
```powershell
C:\dev\guardias-patio\.venv\Scripts\pip.exe install matplotlib>=3.7.0
# Limpiar y recompilar
Remove-Item C:\dev\gdp_dist, C:\dev\gdp_build -Recurse -Force
.\scripts\build_windows.ps1
```

### Error: reportlab faltante
```powershell
C:\dev\guardias-patio\.venv\Scripts\pip.exe install reportlab>=4.0.0
# Si persiste, copiar manualmente después de compilar:
Copy-Item -Path "C:\dev\guardias-patio\.venv\Lib\site-packages\reportlab" `
          -Destination "C:\dev\gdp_dist\GuardiasDePatio\_internal\reportlab" `
          -Recurse -Force
# Recompilar solo instalador
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" "installer_windows.iss"
```

### Error: email_validator presente
```powershell
# Desinstalar del venv
C:\dev\guardias-patio\.venv\Scripts\pip.exe uninstall -y email_validator
# Eliminar del dist si ya compiló
Get-ChildItem "C:\dev\gdp_dist\GuardiasDePatio\_internal" -Recurse -Filter "*email_validator*" | Remove-Item -Recurse -Force
# Recompilar instalador
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" "installer_windows.iss"
```
