# ⌨️ Guía de Atajos de Teclado - Guardias de Patio v2.4

## 🎯 Atajos Globales (Toda la Aplicación)

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| **Ctrl + Tab** | Siguiente pestaña | Cambia a la pestaña siguiente en el orden |
| **Ctrl + Shift + Tab** | Pestaña anterior | Cambia a la pestaña anterior |
| **Ctrl + Q** | Salir | Cierra la aplicación |

---

## 👨‍🏫 Pestaña: Profesores

### Gestión de Lista

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| **Ctrl + F** | Buscar | Enfoca el campo de búsqueda |
| **F5** | Refrescar | Recarga la lista de profesores desde BD |
| **Del** | Eliminar | Elimina el profesor seleccionado (pide confirmación) |
| **Enter** o **Doble Click** | Editar | Carga el profesor seleccionado en el formulario |

### Formulario de Edición

| Atajo | Acción | Descripción |
|-------|--------|-------------|
| **Ctrl + S** | Guardar | Guarda el profesor actual (crear o actualizar) |
| **Esc** | Cancelar | Cancela la edición y limpia el formulario |

## 💡 Tips de Productividad

### 1. Flujo Rápido de Edición
```
1. Ctrl+Tab → Ir a pestaña Profesores
2. Ctrl+F → Activar búsqueda
3. Escribe nombre → Filtrar
4. Enter → Seleccionar primero
5. Doble Click → Editar
6. Modifica campos
7. Ctrl+S → Guardar
```

### 2. Navegación Sin Ratón
```
1. Ctrl+Tab → Cambiar pestaña
2. Tab → Navegar entre campos
3. Espacio → Activar checkbox/botón
4. Enter → Confirmar
5. Esc → Cancelar
```

### 3. Búsqueda Rápida
```
1. Ctrl+F (desde cualquier lugar en Profesores)
2. Escribe término de búsqueda
3. Resultados filtrados instantáneamente
4. ✖ para limpiar búsqueda
```

## 🚀 Atajos Avanzados (Para Usuarios Expertos)

### Combinar Atajos
- **Ctrl+F + Escribe + Enter + Doble Click**: Buscar y editar en 3 segundos
- **Ctrl+Tab (x N)**: Saltar directamente a una pestaña específica
- **F5 + Ctrl+F**: Refrescar y buscar inmediatamente

### Atajos de Sistema Operativo
- **Ctrl+C / Ctrl+V**: Copiar/Pegar en campos de texto
- **Ctrl+A**: Seleccionar todo en campo de texto
- **Ctrl+Z**: Deshacer en campo de texto (antes de guardar)

## 📝 Notas

### Compatibilidad de Teclas
- **Ctrl** = Control en Windows/Linux
- **Ctrl** = Command (⌘) en macOS (PyQt6 lo mapea automáticamente)

### Conflictos con Sistema Operativo
Algunos atajos pueden estar capturados por el SO:
- **Ctrl+Q**: En algunos Linux puede estar usado
- **Solución**: Usa el menú o cambia el atajo del SO

### Accesibilidad
- Todos los atajos tienen equivalente de menú/botón
- No es obligatorio usarlos, solo opcionales
- Ideal para usuarios con problemas de movilidad
