## 🎨 Personalización

### Cómo Ver Atajos en la Aplicación

1. **Tooltips**: Pasa el ratón sobre botones para ver sus atajos
   - Ejemplo: "Guardar (Ctrl+S)"

2. **Menús**: Los menús muestran atajos a la derecha
   - Ejemplo: "Archivo → Guardar  Ctrl+S"

3. **Status Bar**: Algunos contextos muestran hints en la barra de estado
   - Ejemplo: "Presiona F5 para refrescar"

### Cambiar Atajos (Para Desarrolladores)

Para modificar un atajo, editar el código en `setup_shortcuts()`:

```python
# En el archivo del formulario correspondiente
def setup_shortcuts(self):
    QShortcut(QKeySequence("F5"), self, self.refrescar)
    QShortcut(QKeySequence.StandardKey.Save, self, self.guardar)
```

**StandardKey**: PyQt6 proporciona atajos estándar multiplataforma:
- `QKeySequence.StandardKey.Save` → Ctrl+S (Windows/Linux), Cmd+S (Mac)
- `QKeySequence.StandardKey.New` → Ctrl+N / Cmd+N
- `QKeySequence.StandardKey.Open` → Ctrl+O / Cmd+O
- `QKeySequence.StandardKey.Find` → Ctrl+F / Cmd+F

⚠️ **Nota**: Algunos atajos pueden entrar en conflicto con atajos del sistema operativo:

- **Ctrl+Tab**: En algunos navegadores captura este atajo

- **Cmd+Q**: Siempre sale de la aplicación (macOS)
