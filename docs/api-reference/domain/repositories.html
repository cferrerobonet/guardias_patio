domain.repositories

Repository Interfaces para el dominio de Guardias de Patio.

Los repositorios son abstracciones que definen cómo acceder a las entidades sin acoplarse a una implementación específica de persistencia.

Esto permite:

  • Separación de concerns (dominio vs infraestructura)
  • Facilita testing con mocks
  • Permite cambiar implementación sin afectar dominio
