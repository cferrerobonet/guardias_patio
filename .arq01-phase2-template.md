# ARQ-01 Phase 2 — Template Refactoring (4 servicios pendientes)

**Patrón ya demostrado**: `estadisticas_service.py` (v5.15.1)

## Servicios pendientes (en orden: bottom-up, sin dependencias primero)

### 1. `validador_guardias.py` (L398)

**Queries ORM a migrar**:
- `session.query(Guardia).all()` → `guardia_repo.find_all()`
- `session.query(Guardia).filter(Guardia.profesor_id==...).order_by(...)` → `guardia_repo.find_by_profesor(...)`
- `session.query(Ausencia).filter(...)` → `ausencia_repo.find_active_for_profesor(...)`
- `session.query(Profesor).get(id)` → `profesor_repo.find_by_id(id)`

**Cambios**:
```python
# Antes:
def __init__(self, session: Session):
    self.session = session

# Después:
from infrastructure.repositories.repository_factory import RepositoryFactory

def __init__(self, factory: RepositoryFactory):
    self.guardia_repo = factory.create_guardia_repository()
    self.ausencia_repo = factory.create_ausencia_repository()
    self.profesor_repo = factory.create_profesor_repository()

@classmethod
def from_session(cls, session) -> "ValidadorGuardias":
    return cls(RepositoryFactory(session))
```

**Ubicación**: Clase `ValidadorGuardias` (línea ~50), métodos que necesitan cambio: `validar_todo`, `validar_guardias_completo`
